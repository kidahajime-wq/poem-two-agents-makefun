A short program that writes one poem about agency — the power to choose
and to act — to `/output/entry.txt`. Two voices, one plan: each agent gives
up one thing (being right, being first), and the plan that walks out of the
gap between them belongs to neither alone.

Run it:

```sh
python3 main.py
```
